# Mathematics in ordinary notes

Keep the argument, calculations and remaining question in the documents already
in use. Link supporting notes at the relevant heading. **Contents**, a preview
link or **Follow Document Link** opens the supporting passage;
**Return to Document** returns to the originating link.

Save through the authoring application. Before stopping, leave the unfinished
step in the working note. Use **Reopen Document** for the last file or
**Recent Documents…** for another. An exact saved selection is restored only
while it still matches. PDF pages, preview scroll positions and live kernels
are not restored.

**New Note…** uses the configured notes application and template; see
[notes applications](NOTE_COMPANIONS.md). Calculations remain in Jupyter or
SagePod. [Retain a notebook result](NOTEBOOK_RESULTS.md) to keep its saved inputs
and outputs beside the argument. Reopening that result does not execute it.

No study record, question form or justification context is required.

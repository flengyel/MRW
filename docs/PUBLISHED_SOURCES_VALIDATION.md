## Removed steps and remaining limits

Kerodon reading no longer requires manually copying its page into a text source
and building passages. The full Stacks Project name distinguishes the command;
qualified IDs distinguish coincident local tags. Existing citation insertion,
reader links, backlinks and study handoffs carry that identity automatically.
The tutorial includes both import routes and explains identity versus revision.

Kerodon acquisition is one page, not recursively linked subsections. External
prerequisites still require explicit acquisition or browser navigation. Canonical
pages may change; there is no cross-version annotation relocation. Unsupported
HTML/media uses the retained-source fallback. Backlinks remain bounded and
folder-scoped. nLab has no importer in this release. These source/structure tests
establish no checked mathematics or learning benefit. General research resumption
and argument reconstruction remain the next designed integrations.

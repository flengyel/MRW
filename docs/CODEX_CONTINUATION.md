# Continue MRW development

Read [AGENTS.md](../AGENTS.md), the mandatory
[documentation requirements](../CONTRIBUTING.md#documentation), the
[development plan](../CODEX_PLAN.md) and the
[design register](DESIGN_RECONCILIATION.md). Current user instructions determine
the task; the register supplies its governing requirements and verified status.

## Resume the authorized task

Inspect current main, the working tree and relevant source before changing
anything. Preserve uncommitted work, ordinary documents, private stores, drafts
and open requests. Establish the actual workspace and installation from current
evidence rather than copying a path or version from an earlier session.

Continue the stated objective and unresolved findings. A follow-up question
refines that objective unless it explicitly replaces or cancels it. Do not repeat
a delivered increment or restore a removed interaction from an old prompt.
Proposed capabilities in a design document do not authorize their implementation.

Use the existing workflow and owner application first. The
[integration contract](INTEGRATION_BOUNDARIES.md) governs delegation and failure;
the [native-test procedure](NATIVE_TEST_ISOLATION.md) governs mutation tests.
Opening a note starts no exercise. Source study and proof study begin when
the reader selects the corresponding command.

## Verify and complete

Run checks appropriate to the changed behavior. Distinguish source inspection,
component tests, native observations and mathematical-use evidence. Keep unknown
or unavailable checks explicit. Documentation-only work needs checked examples,
commands and links, not an unrelated runtime test campaign.

Update affected guides with the implementation and record changed status once
in the register. Put the problem, changes, verification and remaining issue in
the commit or pull-request description. Follow the
[release procedure](RELEASING.md) when release work is authorized. Report source,
package and installation separately; publishing an update does not authorize
installing it or reloading a working window.

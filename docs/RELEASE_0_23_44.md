## Delivered interaction

[Select text or retained passages](SOURCE_GROUNDS_WORKFLOW.md), copy their exact
text/references/revisions and schema to Codex, import the attributed response,
correct summaries, explicitly admit selected grounds and then search. Captures,
original responses and corrections are immutable revisions in the existing
artifact store. Admission records the local reader/time separately from supplied
producer attribution. Rejected writes preserve the prior view; uncertain
acceptance retries reuse the exact saved context. Withdrawal retains proposal
provenance through predecessor/restart inspection.

A native restart exposed competing catalog reads under the coordinator's
nonblocking lock. The reader now performs those reads sequentially; a focused
regression rejects overlap. The coordinator, lock rules and storage authority
were preserved. No study, problem or question registration form was added.

| Manual work removed | Remaining reader action |
| --- | --- |
| Compose a route-context JSON file, hashes and source-reference bindings | Select the source text or retained passages |
| Copy each passage and revision separately | Copy one bounded handoff |
| Edit claim summaries inside JSON | Edit summary/title in the reader |
| Recreate captured material and corrections after closure | Reopen the saved selection/proposal |
| Reconstruct accepted grounds after interrupted checking | Reopen the exact unfinished context and explicitly retry |

Clipboard exchange with the companion remains manual. It must return the
bounded schema. Changing arrows, scope or goal requires another proposal.
Supplied producer identity is not authenticated. Mathematical judgment remains
necessary; usefulness in a stopped and resumed research investigation was not
established by the synthetic acceptance trial.

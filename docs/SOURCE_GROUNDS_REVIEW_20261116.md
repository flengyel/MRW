# Source-ground workflow: writing review

Scope: the complete new [workflow](SOURCE_GROUNDS_WORKFLOW.md), its injection
example, the updated Euclid introduction and current README/tutorial directions.
Existing Artemov–Fitting citations and logical scope from main were preserved.
No manuscript or external Zettelkasten note was edited.

The workflow opens with the mathematical use, then gives selection, handoff,
review, admission and search in that order. The explanation of a ground precedes
the injection example. The example declares the sets and both function types,
states the conclusion and proves it by applying injectivity twice. Current
limits follow the worked interaction.

The governing source was Knuth, Larrabee and Roberts,
[*Mathematical Writing*](https://www-cs-faculty.stanford.edu/~knuth/papers/cs1193.pdf),
§1, especially points 5, 10–13 (printed pp. 2–3; PDF pp. 4–5): statement scope,
connected prose, definitions at use, motivation and readable prose around
formulas. These principles support the explicit types and short connected proof;
the interaction order is an editorial choice, not a rule attributed to the book.

The changes remove a generic promotional introduction, define the arrow's
premise order, keep source/producer/admission/check distinctions at their point
of use, and replace obsolete claims that all context assembly requires JSON
editing. Existing labels and proof hypotheses were retained. Code fences and
source text are handled as quoted data in the companion handoff.

Source text and generated reader controls were reviewed. Component checks cover
visible claims, arrows, exact sources and explicit selection. Actual native
observation and package checks belong in the release report; this review alone
establishes neither native behavior nor mathematical certification.
